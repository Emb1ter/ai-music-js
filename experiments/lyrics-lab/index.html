What this isolates

        
Read the comparison carefully

        
    
          
  • All variants in one run use the selected model and the same lyric seed.
    • 
          
  • D, F, G, H, I and J share one strict user prompt. K is the locked lightweight control; O changes only its structure sentence, P adds L's system prompt, and Q adds a literal-sense gate plus counting headroom.
    • 
          
  • The preset briefs cover awkward humor, grief, causality, mundane detail, mixed emotion and place-specific celebration.
    • 
          
  • Processed output applies the library's existing cleanup and word-budget compaction.
    • 
          
  • Raw output reveals whether the prompt or post-processing caused a bad result.
    • 
          
  • Variant E exposes pass 1 separately, so fact-extraction errors are not confused with songwriting errors.
    • 
          
  • Run several seeds before adopting a prompt; one lucky generation is not a quality result.
